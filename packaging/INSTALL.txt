Spicy Weeks for Heroes of Might and Magic: Olden Era
====================================================

Neutral invasion weeks on random maps (and hand-made maps without a script), in the spirit of Heroes 3's "Month of the ...":
on some weeks stacks of creatures appear all over the map, growing stronger as the game
goes on and following the neutral difficulty picked in the lobby. Most invasions are a horde with a different creature from any faction in every
stack; some are a single creature, Heroes 3-style. Each invasion has
a mood that sets how willing its stacks are to join a hero, and the astrologer
announces it in place of the usual week effect. For only single-creature weeks,
set MixedChancePercent = 0 in the settings file.

It also bans Month of Clarity (the month that reveals the whole map): when the
astrologer rolls it, the month is Calm instead. More effects can be banned in
the settings file (BannedEffects).

INSTALL (Windows)
-----------------
1. Close the game.
2. In Steam: right-click Olden Era > Manage > Browse local files.
3. Extract everything from this zip into that folder, keeping the folder structure.
   You should end up with winhttp.dll and a BepInEx folder next to HeroesOldenEra.exe.
4. Start the game. The FIRST start takes a few extra minutes on the splash screen while
   BepInEx prepares itself; later starts are normal.

MULTIPLAYER
-----------
Every player needs the same Spicy Weeks version AND the same settings file
(BepInEx/config/olden-era-mods.spicy-weeks.cfg, included in this zip).
Different settings produce different invasions and the game will desync.
Do not edit the settings unless everyone in the game makes the same change.

UNINSTALL
---------
Delete winhttp.dll from the game folder (or set enabled = false in doorstop_config.ini).
Delete the BepInEx and dotnet folders to remove everything.

GAME UPDATES
------------
A game patch may break the mod. If it does, BepInEx logs a warning
(BepInEx/LogOutput.log) and the game runs without invasions until a new version is out.

MAC (CrossOver / Whisky / other Wine wrappers)
----------------------------------------------
Under Wine three extra steps are needed, all inside the Wine bottle:
1. DLL override for HeroesOldenEra.exe: winhttp = native,builtin
   (registry: HKCU\Software\Wine\AppDefaults\HeroesOldenEra.exe\DllOverrides,
   value name "*winhttp" if the bottle has a global "*winhttp" entry).
2. Environment variable DOTNET_SYSTEM_GLOBALIZATION_INVARIANT=1 for the bottle
   (registry: HKCU\Environment), otherwise .NET crashes on Wine's icu.dll.
3. Nothing else: the Unity libraries BepInEx would normally download are already included
   (BepInEx/unity-libs), because .NET under Wine cannot make HTTPS requests.
